# Browser AI Image Enhancer

Браузерное приложение для локального улучшения яркости, контрастности и насыщенности изображений. Обработка выполняется в браузере пользователя; API-ключи и сервер не требуются.

## Публичная демонстрация через GitHub Pages

1. Загрузите содержимое этого проекта в корень публичного GitHub-репозитория.
2. Откройте `Settings → Pages`.
3. Выберите `Deploy from a branch`.
4. Укажите ветку `main` и папку `/docs`.
5. Сохраните настройки.

## Локальная проверка

```bash
npm ci
npm run verify
npm run preview
```

Готовый сайт находится в `docs/`, исходный код — в `src/`, тесты — в `tests/`, обучение модели — в `training/`.
